## Практикум 8 — події, форми та валідація

Форма «Додати роботу» містить обов'язкові `title` і `year` (`number`, `min=2000`, цілий рік) та `category` (`select`). На `input` рік у майбутньому отримує власне повідомлення через `setCustomValidity()`, яке зникає після виправлення; верхня межа визначається через `new Date().getFullYear()`. Назва з одних пробілів також відхиляється.

Обробник `submit` починається з `event.preventDefault()`, зчитує `.value`, перетворює рік через `Number`, додає об'єкт у `works`, викликає `renderProjects()` і очищає форму через `form.reset()`. Новий об'єкт зберігає поля `title`, `year`, `category`, `image`, `alt`; зображення — локальний навчальний ескіз.

Окремий фільтр категорій на `change` використовує `classList.toggle('hidden', ...)`. У DOM залишаються всі картки, а на сторінці показано вибрану категорію. Фільтр зберігається після додавання; лічильники показують загальну та видиму кількість робіт.

Перевірка: порожні обов'язкові поля, пробіли в назві, 1999, майбутній та дробовий рік блокують додавання; 2000 і поточний рік дозволені. Коректний запис одразу з'являється без зміни URL та дублювання карток, форма очищається. Нові записи зберігаються лише в пам'яті до перезавантаження сторінки.

## Практикум 7 — маніпуляція DOM

`script.js` створює шість карток у `#gallery` з масиву `works` практикуму 6. Статичні картки в HTML видаляються через `remove()`. `renderProjects()` використовує `createElement`, `textContent`, `append`, атрибути зображень і `data-category`/`data-year`. Роботи 2024–2026 років отримують клас `recent` за функцією `isRecent`. Лічильник `#projects-count` показує загальну кількість робіт. Повторний рендер не дублює картки.

Зображення — локальні навчальні SVG-ескізи, успадковані від попередніх робіт. Попередню адаптивну сітку й дизайн збережено.

Для локального запуску відкрийте проєкт у Rider та запустіть HTTP-сервер з кореня проєкту, наприклад `python3 -m http.server 8000`. Відкрийте `http://localhost:8000`.
