## Практикум 7 — маніпуляція DOM

`script.js` створює шість карток у `#gallery` з масиву `works` практикуму 6. Статичні картки в HTML видаляються через `remove()`. `renderProjects()` використовує `createElement`, `textContent`, `append`, атрибути зображень і `data-category`/`data-year`. Роботи 2024–2026 років отримують клас `recent` за функцією `isRecent`. Лічильник `#projects-count` показує загальну кількість робіт. Повторний рендер не дублює картки.

Зображення — локальні навчальні SVG-ескізи, успадковані від попередніх робіт. Попередню адаптивну сітку й дизайн збережено.

Для локального запуску відкрийте проєкт у Rider та запустіть HTTP-сервер з кореня проєкту, наприклад `python3 -m http.server 8000`. Відкрийте `http://localhost:8000`.
