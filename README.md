# Трекер настрою Ростислава Пашка

Пашко Ростислав, ІП-53. Практикум 7, варіант 3.

Контейнер `#mood-history` отримує `article` для кожного об’єкта `{ date, mood, note }`. Дата виводиться в `h3`, нотатка — в `p`, оцінка — в `data-mood`. `moodToLabel` повертає текстову назву рівня, а словник `moodClasses` зіставляє її з `good`, `neutral` або `hard`. Текстова оцінка доступна незалежно від кольору.

`renderMoodHistory()` видаляє попередні картки через `remove()`, використовує `createElement`, `textContent` та `append` і оновлює `p#avg-mood`. Сума навчальних оцінок — 19; середнє шести записів — 3,17. Порожній список показує повідомлення без NaN. Класифікація періоду використовує поріг 3.

Початкові записи є навчальними прикладами. Повторний рендер не створює дублікатів. На ширинах 375, 768 та 1280 px — відповідно 1, 2 та 3 колонки.

Запуск із кореня проєкту: `python3 -m http.server 8000`, потім http://localhost:8000.
